Getting Started

ElliDesk is a web console for day-to-day Active Directory administration — user accounts, groups, computers, and directory cleanup — without needing the Active Directory Users and Computers (ADUC) snap-in or ADSI Edit.

Signing in

Go to the app and sign in with your normal BOS domain username and password (the same one you use to log into your Windows machine). There's no separate account to create.

Access is currently limited to accounts under the ICT/MIS organizational unit. If you sign in with correct credentials but see "not authorized," it means your account isn't in scope yet — contact whoever administers ElliDesk to be added.

Sessions last 8 hours, after which you'll need to sign in again.

Dashboard

The landing page after login. It shows at a glance:

  • Total, enabled, disabled, and locked user counts
  • Total groups, split into security vs. distribution
  • A warning banner if any accounts are currently locked out, linking straight to them
  • A grid of every tool in the app ("Quick Actions") as the fastest way to get around

You can also navigate using the menu bar at the top of every page, which links directly to Users, Groups, OUs, Computers, Maintenance, and Audit Logs.

Managing Users

Users → All Users lists every account in the directory. Use the search box and the three filter dropdowns (Status, Locked, Department) together to narrow the list — for example, "Locked Only" plus a specific department finds exactly who needs unlocking in that team.

Actions on a user

Click Actions on any row for a menu with:

  • View — opens the full user detail page
  • Enable / Disable — toggles whether the account can log in anywhere
  • Unlock — only shown when the account is currently locked out
  • Reset Password — opens a dialog described below

Resetting a password

The Reset Password dialog generates a strong random password for you automatically (with a Regenerate button if you want a different one). Two checkboxes, both on by default:

  • User must change password at next logon — forces them to set their own on first login
  • Unlock account — clears any existing lockout at the same time

After a successful reset, the password is shown once with a copy button — AD doesn't let the app retrieve it again after that, so copy it before closing the dialog.

This action currently errors out — see Known Issues below. It will start working as soon as the LDAPS certificate is in place; nothing else needs to change on your end.

User detail page

Clicking a user's name (or "View") opens their full record: General, Account, Organization, and a raw Attribute Editor tab that shows every AD attribute on the object — useful for troubleshooting. The same Enable/Disable, Unlock, and Reset Password actions are available here too.

Adding a New User

Add New User (from the Dashboard) creates a new AD account. Fill in name, username, UPN (email-style login), and pick a department — the department determines which OU the account is placed in and which groups it's added to automatically.

New accounts are created disabled and without a password on purpose. Use Reset Password afterward to set an initial password — that's also what enables the account for use. Because Reset Password is temporarily unavailable, newly created accounts can't be activated until that's resolved either.

Groups

Groups lists every security and distribution group, with search and filters by type and OU. Click a group to see its members, or use the row menu to edit its description, email, or manager, view members, or delete it entirely.

From a group's member list you can add or remove members directly — search for a user, add them, or remove existing members with one click. Changes take effect immediately in AD.

Organizational Units

OUs shows the full organizational unit tree on the left — click any folder to expand it, and click its name to load the users inside it on the right. A user-count badge on each OU includes everyone in its sub-OUs. Toggle Include sub-OUs to see everyone underneath a branch, not just users directly in that one folder.

Computers

Computers lists every computer object in the domain with its OS, OU, last logon, and enabled/disabled status. Filter by status, operating system, OU, or inactivity (e.g. "Inactive 90+ days"). Click a row for full details, and enable or disable the computer account directly.

Maintenance Hub

Maintenance is home to three cleanup and bulk-action tools. Each one runs a full preview before writing anything to AD, so you always see exactly what's about to happen first.

Offboarding

The tool for retiring an account when someone leaves. It's a four-step wizard:

  1. Select Users — search and add one or more people to offboard
  2. Actions — choose any combination of: remove from all groups, disable the account, and/or move it into the FE_RETENTION OU. All three are on by default
  3. Preview — shows each person's current OU, every group they'll be removed from, and whether they're already disabled, before anything happens
  4. Apply — runs it, then shows a per-person result you can export to CSV
Accounts belonging to protected groups (Domain Admins, Enterprise Admins, Schema Admins, Administrators) are automatically excluded from offboarding as a safety measure.

Accounts are moved and disabled, never deleted — everything in FE_RETENTION is fully recoverable later if needed.

Bulk Update

Change one attribute (Department, Job Title, Company, Office, Description, or Manager) across many users in one pass. Scope your target group either by OU (with an option to include sub-OUs) or by manually searching and selecting specific people, then set the new value and load a preview before applying. Results are exportable to CSV.

Reports

Three directory-hygiene reports, each with a CSV export button:

  • Inactive Devices — enabled computers with no logon activity in the last 30/60/90/180 days
  • Stale Accounts — enabled user accounts with no logon activity over the same thresholds — good candidates to check before offboarding
  • Non-Expiring Passwords — every account with "password never expires" set, a standard item to review periodically

Password Policy

A read-only view of the domain's default password policy (minimum length, history, age, complexity, and lockout settings) plus any Fine-Grained Password Policies (PSOs) configured on the domain. This page doesn't let you change anything — policy changes are made through Group Policy, as usual.

Audit Logs

Every change made through ElliDesk is recorded here automatically — logins, password resets, account enable/disable/unlock, offboarding, bulk updates, and all group and computer changes. Filter by action type, success/failure, a date range, or free-text search. Click any row for full details.

This is the first place to check if you need to know who did what, or when.

Known Issues

Password Reset is temporarily unavailable

Active Directory refuses to accept a new password over a connection that isn't encrypted, so ElliDesk connects using StartTLS specifically for that one action. Our domain controller doesn't yet have the self-signed certificate installed for LDAPS/StartTLS, so right now Reset Password will fail with a connection error every time it's used — this includes activating brand-new accounts created via Add New User, since activation is done through the same Reset Password flow.

This is being worked on and doesn't affect anything else in the app — search, viewing, enable/disable, unlock, groups, OUs, computers, offboarding, bulk update, reports, and audit logs are all fully working today. Once the certificate is installed, password resets will start working immediately with no changes needed on your end.

Getting Help

If something looks wrong, isn't reflecting a change you expect, or you're not sure whether an action is safe to take (especially Offboarding or Bulk Update), check the Audit Logs page first — it usually explains what actually happened. Otherwise, reach out to whoever administers ElliDesk in ICT.

This guide is also available inside the app at /help, where it will stay up to date as features change. This document is a point-in-time copy for reference offline or outside the app.
